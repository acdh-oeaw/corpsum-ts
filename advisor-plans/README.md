## Dependency Notes

- Plans 003-005 can be implemented independently, but plan 002 should land
  first if this work is going through CI, because the current workflow installs
  Playwright and then runs `pnpm run test`, which is only `exit 0`.
- Plan 003 should include API or server-level tests; if plan 002 has not landed,
  run those tests locally and call out that CI will not yet enforce them.
- Plan 004 changes a runtime dependency and a server endpoint; keep it isolated
  from unrelated export UX work.
- Plan 005 is intentionally narrow. Do not fold broader visualization query
  routing or publishing cache fixes into it.
- Plans 006-008 are already represented by the temporal component, visualization
  contract, and toolbar refactor now present on `dev`; their previously missing
  index rows are recorded as DONE.
- Plan 009 is the shared query-routing foundation for Plans 010, 011, 013, and 014. It must land before those plans so later work consumes one aligned
  per-query result model.
- Plan 012 is independent and can run in parallel with Plans 009-011, but it
  should land before Plan 014 reuses the source table for the remaining
  components.
- Plan 013 may find that Plan 009 already removed most of the faulty regional
  state. Its independent responsibility is to remove any residual
  history-based alignment and add reorder/removal/timing regression coverage.
- Plan 014 intentionally shares the display protocol without sharing query
  mechanics: word frequencies, collocations, and KWIC are not metadata-driven
  and keep endpoint-specific descriptors and cache identities.

## Data-Display Scope Decisions

- A universal visualization base component or settings blob is rejected. Plans
  009-014 standardize boundaries and ownership while keeping type-specific
  settings, transformations, and query mechanisms.
- Future geospatial, personal, organisational, and other analysis settings are
  not designed speculatively in Plan 010. The plan establishes the typed codec
  extension point they will use when their product semantics are known.
- Collocations, word-form frequencies, and KWIC do not receive metadata
  mappings in Plan 014. They adopt the live/snapshot/presentation protocol but
  preserve endpoint-specific non-metadata queries.

# Keyword in Context (KWIC)

![Abbildung: Keyword in Context (KWIC)](/assets/documentation/de/image43.png)

Hier werden die Belege im Kontext, d.h. rund um die Suchanfrage angezeigt. Zusätzlich können auch Metadatenannotationen angezeigt werden (per Klick auf ![Abbildung: Keyword in Context (KWIC)](/assets/documentation/de/image44.png)). Eine Verfeinerung der Darstellung ist überdies durch Auswahl spezifischer ![Abbildung: Keyword in Context (KWIC)](/assets/documentation/de/image45.png) möglich. Eine darüber hinausgehende Anzeige sowie weitere Optionen zur Betrachtung der Einzelbelege sind über die NoSketch-Enginge des amc verfügbar.

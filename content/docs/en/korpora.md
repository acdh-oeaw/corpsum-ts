# Corpora

This menu item lists the corpora you have used so far. Use the arrow buttons ![Corpora](/assets/documentation/de/image14.png)![Corpora](/assets/documentation/de/image15.png) to move between them.

If the list is empty, go to **Queries**, select a corpus, and define a query.

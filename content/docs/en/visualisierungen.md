# Visualizations

## Saved visualizations

This page lists your saved visualizations. The controls ![Visualizations](/assets/documentation/de/image47.png) let you reopen a visualization (first option), edit it (second option), or delete it (third option).

## Create a visualization

To create a visualization, click ![Visualizations](/assets/documentation/de/image48.png).

Enter a name in the **Name** field. Under **Queries**, click ![Visualizations](/assets/documentation/de/image49.png) to add queries you have already run. In the pop-up, select the queries using the checkboxes and click **Save**. Then select the visualization types you want:

- data-display-collocations: collocations chart
- data-display-keyword-in-context: keyword in context (KWIC) results
- data-display-media-source: media sources chart
- data-display-media-type: media types chart
- data-display-regional-frequencies: regional frequencies chart
- data-display-word-form-frequencies: word form frequencies chart
- data-display-metadata-temporal-frequency-distribution: frequencies over time chart

Click **Create** ![Visualizations](/assets/documentation/de/image50.png) to save the visualization.

## Publish a visualization

To share a visualization with others, select it and click **Publish** ![Visualizations](/assets/documentation/de/image51.png). Enter the required information ![Visualizations](/assets/documentation/de/image52.png) to obtain a public URL and embed code. Use the embed code to display the visualization on another website. After publication, both are also available under **Published panels**.

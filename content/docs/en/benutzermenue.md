# User menu

The user menu contains the following entries:

![User menu](/assets/documentation/de/image10.png)

Click **Start** to return to the CorpSum start page.

**Account settings** is reserved for future use.

Under **Credential management**, you can manage your credentials for corpora you already have access to. For example, to work with the Austrian Media Corpus (amc) in CorpSum, you need access to the amc. You can [request access here](https://amc.acdh.oeaw.ac.at/access-conditions/). Once you receive your credentials, enter your username and password in the corresponding fields and click **Save**. If your credentials change, update them in the same fields and save again. When you enter and save valid credentials, you will see the following: ![User menu](/assets/documentation/de/image11.png)

Click **Log out** to end your session and return to the login page.
